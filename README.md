# PizzaPlanet
🍕 Pizza Planet Delivery é uma plataforma web de delivery inspirada no universo Toy Story, criada para oferecer uma experiência divertida e eficiente de pedidos online. Clientes podem visualizar o cardápio, montar pedidos e acompanhar o status em tempo real, enquanto o restaurante gerencia produtos e entregas de forma simples e intuitiva. 🚀
